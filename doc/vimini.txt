INTRODUCTION                                          *vimini-introduction*

This is a Vim plugin to use Gemini via APIs written in Python 3.

==============================================================================
USAGE                                                         *vimini-usage*

Install the plugin using your favorite plugin manager.

==============================================================================
COMMANDS                                                    *vimini-commands*

*:ViminiChat*
    Opens the interactive chat window to communicate with Gemini.

*:ViminiCommit* [-n] [-r] [-a] [instruction]
    Generates a commit message and commits changes using Gemini.
    Files included in the commit are shown in the diff stat comments at the
    bottom of the buffer. In Normal mode, press <Space> on a file to toggle its
    inclusion
    (deselected files are marked with -), or delete the file's line. When
    saved and closed, deselected files are removed and only remaining files are committed.
    -n: Omit co-author trailer.
    -r: Regenerate commit message for HEAD and amend.
    -a: Amend working tree changes into HEAD and regenerate commit message.
    [instruction]: Optional hint for the commit message generation.

==============================================================================
CONFIGURATION                                           *vimini-configuration*

g:vimini_user_name
    Set this variable in your |vimrc| to customize the greeting message.
    Example: >
        let g:vimini_user_name = 'Alice'
    <
    Default: 'Vim User'
